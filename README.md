# 化肥使用全书，及时更新，不断完善。

## 常规化肥:通常按提供的植物营养元素分类。

### 一、大量元素肥料（N、P、K）

这是农业生产中使用量最大的三大类。

类别	常见品种	主要养分
氮肥（Nitrogen Fertilizers）	尿素、碳酸氢铵、硫酸铵、氯化铵、硝酸铵、硝酸钙、硝酸钾	N
磷肥（Phosphate Fertilizers）	过磷酸钙、重过磷酸钙、钙镁磷肥、磷酸一铵（MAP）、磷酸二铵（DAP）	P
钾肥（Potash Fertilizers）	氯化钾、硫酸钾、硝酸钾	K
二、复合肥（Compound Fertilizers）

同时含有两种或三种大量元素。

常见产品：

15-15-15
17-17-17
18-18-18
20-10-10
18-46-0（DAP）
11-52-0（MAP）

根据养分数量可分为：

二元复合肥（NP、NK、PK）
三元复合肥（NPK）
三、中量元素肥料（Secondary Nutrient Fertilizers）

植物需求量仅次于 N、P、K。

元素	常见肥料
钙（Ca）	石膏、硝酸钙、过磷酸钙
镁（Mg）	硫酸镁、氧化镁、白云石粉
硫（S）	硫酸铵、硫酸钾、石膏、元素硫
四、微量元素肥料（Micronutrient Fertilizers）

包括：

硼肥
硼砂
硼酸
锌肥
硫酸锌
EDTA 锌
铁肥
硫酸亚铁
EDDHA 铁
EDTA 铁
锰肥
硫酸锰
铜肥
硫酸铜
钼肥
钼酸铵
钼酸钠
氯肥
氯化钾（兼供 K 和 Cl）
五、水溶肥（Water-soluble Fertilizers）

全部可溶于水，主要用于滴灌、喷灌、叶面喷施。

典型产品：

磷酸二氢钾
硝酸钾
硝酸钙
磷酸一铵
磷酸二铵
全水溶 NPK（20-20-20、30-10-10 等）
六、缓控释肥（Slow-/Controlled-release Fertilizers）

释放养分速度较慢，提高利用率。

包括：

包膜尿素
树脂包膜肥
硫包膜尿素
聚合物包膜复合肥
七、稳定性肥料（Stabilized Fertilizers）

通过添加抑制剂减少养分损失。

主要有：

脲酶抑制剂肥料
硝化抑制剂肥料
稳定性尿素
稳定性复合肥
八、液体肥料（Liquid Fertilizers）

包括：

液体氮肥（UAN）
液体复合肥
液体磷肥
液体钾肥
九、专用肥（Specialty Fertilizers）

根据作物设计配方，例如：

水稻专用肥
玉米专用肥
小麦专用肥
柑橘专用肥
茶树专用肥
烟草专用肥
果树专用肥
蔬菜专用肥
十、其他常见肥料
有机无机复混肥
腐殖酸肥料
氨基酸肥料
海藻肥
生物有机肥
微生物菌剂
生物刺激素（Biostimulants）（严格来说通常不属于传统化肥）
常规化肥体系（建议作为教材目录）

如果编写《化肥使用全书》，建议按以下体系组织内容：

氮肥（Nitrogen Fertilizers）
磷肥（Phosphate Fertilizers）
钾肥（Potash Fertilizers）
复合肥（Compound Fertilizers）
中量元素肥料（Calcium, Magnesium, Sulfur）
微量元素肥料（B、Zn、Fe、Mn、Cu、Mo、Cl、Ni）
水溶肥（Water-soluble Fertilizers）
缓控释肥（Slow- and Controlled-release Fertilizers）
稳定性肥料（Stabilized Fertilizers）
液体肥料（Liquid Fertilizers）
专用肥（Specialty Fertilizers）
新型肥料（如腐殖酸肥料、海藻肥、生物刺激素等）
